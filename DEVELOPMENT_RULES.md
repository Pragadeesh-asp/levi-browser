# LEVI BROWSER Development Rules

These rules apply to all future milestones:

1. Work on one small milestone at a time.
2. Inspect existing code before editing.
3. Never unnecessarily rewrite working implementations.
4. Run relevant tests after modifications.
5. Update `PROGRESS.md` after every milestone.
6. Commit every independently completed milestone.
7. Never push unfinished or unverified work.
8. Preserve Alpha/Beta profile isolation.
9. Never commit browser session data or credentials.
10. If interrupted, leave enough documentation for another session to resume safely.
